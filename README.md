# LiveSolve — 휴대폰 카메라 실시간 문제 풀이 (공부용)

휴대폰으로 이 페이지를 열고 카메라로 문제를 비추면, Claude가 문제를 읽고 정답(또는 풀이)을 화면과 음성으로 알려 줍니다.

- 주소: https://leguchuei.github.io/livesolve/
- 처음 한 번 Anthropic API 키를 입력합니다. 키는 **그 휴대폰 브라우저에만 저장**되며 이 저장소에는 들어 있지 않습니다.
- Chrome 메뉴(⋮) → 홈 화면에 추가 하면 앱처럼 쓸 수 있습니다.
- PC 연결 방식(`app.py`)은 별도 배포본에 있습니다.
