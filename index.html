LiveSolve

카메라로 문제를 비추면 실시간으로 풀어 드려요

console.anthropic.com → API Keys 에서 만든 키를 붙여넣으세요. 키는 이 휴대폰 브라우저에만 저장됩니다.
  1. 문제가 화면의 네모 안에 들어오게 비춥니다.
  2. 1초쯤 가만히 들고 있으면 자동으로 인식해 풀이가 올라옵니다.
  3. 다음 문제로 옮기면 또 자동으로 풉니다. 가운데 버튼은 즉시 풀기.
  4. 글자가 작으면 두 손가락으로 벌려 확대, 흐리면 화면을 탭해 초점을 맞추세요.
  5. 더 선명하게 찍고 싶으면 왼쪽 '고화질' 버튼 → 카메라 앱으로 찍어서 풉니다.
  6. 정답은 음성으로도 읽어 줘요(🔊). 블루투스 이어폰을 연결해 두세요.
